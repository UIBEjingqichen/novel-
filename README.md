# 《未定海》岐轮城三维运行验证器

这是用于检查岐轮城市结构与日常运行逻辑的交互式 3D 沙盘，不是最终视觉设定图，也不是工程有限元模型。

## 当前版本可检查

- 中央定轴、各高度环架与辐桥
- 普通可迁住宅组团的局部径向伸缩
- 固定辐向住宅带与普通住宅区的区别
- 无连续建筑的主干交通净空
- 学校只在有限服务运行段内移动，不绕整城周转
- 顶部空运、下部生产物流的边界功能差异
- 24 小时轮历时间轴
- 太阳方向与实时阴影
- 完整城市、单层、剖面、骨架、空隙五类观察方式
- 祝遥与普通学生/居民的示意通行路线

## 关于正典

页面中的“7 个高度层、4 条固定辐向住宅带、12 个住宅弧段”等数量，只是为了让三维沙盘能够运行和观察的建模参数，不是《未定海》正典数字。

模型遵守的核心正典约束：

1. 岐轮保持固定外轮廓、内部持续换位。
2. 环架闭合不代表住宅、学校或普通工厂每天绕城一圈。
3. 普通住宅日常只在所属生活运行段内有限迁位，例如 A1 到 A3 一类局部换位。
4. 固定辐向住宅带依附固定骨架，不参加普通住宅用于采光与接驳的日常伸缩。
5. 固定辐向住宅带可以有连续住宅、商铺与街区一路接向中央；相邻主干交通带为交通、撤离、消防和大型运输保持净空。
6. 多高度生活区通过错位、开放间隙与伸缩共同处理自然采光。
7. 中间多数生活高度在功能上大体同质；明显的垂直功能偏差主要来自地面与天空两个边界。

## 打开方式

`index.html` 是完整的静态网页，不需要 npm、Vite 或编译。它通过 CDN 加载 Three.js，因此浏览器需要能访问互联网。

在 GitHub 仓库页面点击 `index.html` 只会看到源代码，这是 GitHub 的文件查看器行为。应通过 GitHub Pages 地址打开交互网页。
